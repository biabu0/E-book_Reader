# E-book_Reader
  简单实现了一个支持utf-8编码文件，使用freetype矢量字体库，通过Framebuffer在LCD上显示电子书的程序。
# 主要模块
  进行分层处理，最上层为main主函数，此后为draw，来处理显示逻辑；之后通过三个模块管理不同的编码格式、字体文件和显示设备；
  ## 文件编码
      实现对UTF-8编码文件的解析和输出，获取unicode编码。
  ## 字体
      freetype根据Unicode码返回点阵数据，这个点阵数据是在笛卡尔坐标上的，需要进行处理才能够在LCD上显示。
  ## 显示
      通过mmap存储映射直接操作内存显示像素
